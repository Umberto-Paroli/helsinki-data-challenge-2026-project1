# Helsinki Data Challenge 2026 - Team UNIMORE - Solution 1

## Installation
We recommend using a virtual environment or a container to manage project dependencies.
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

## Data
Before running the code, add the asteroid lightcurves and the `.stl` files of the public objects to a **`./Data`** directory. Real videos and Blender renderings are not required. 

## Usage
Running [`search.py`](./search.py) finds the best hyperparameter configuration for the three public objects available from the data challenge. \
The resulting values must be replicated in the configuration files for each unknown object, making sure to update the lightcurve file path and the `cylinder_radius`, since they differ for each object. \
The configuration files provided in this repository were generated by running:
```bash
python search.py --phase convex --hours 24
python search.py --phase refine --hours 24
```

If your data directory is different from `./Data`, change the lightcurve paths in the configuration files:
```yaml
  data:
    intensity_file: <LC_INTENSITY_PATH>
    binary_file: <LC_INTENSITY_BINARY>
    intensity_file_blender: <LC_BLENDER_INTENSITY_PATH> # only if this object has published Blender data
    binary_file_blender: <LC_BLENDER_BINARY_PATH>
```

You can also change the output directory if required:
```yaml
  output:
    base_dir: ./runs_unknown/[N] # if desired
```

Once the configuration files are ready, update [`run_unknown_object.py`](./run_unknown_object.py).
To execute the full pipeline, run:
```bash
python ./run_unknown_object.py
```

You can also manually call each script, but doing so requires updating the `_PERIOD_` and `_CHECKPOINT_` variables in the `config_convex` and `config_calibrate` files.
Run the following commands in sequence:
```bash
python main_convex.py ./config_calibrate_unknown.yaml
python main_convex.py ./config_convex_unknown.yaml
python main.py ./config_refine_unknown.yaml
```

## Saved Configuration Files
To simplify the process and avoid running the hyperparameter search, we have included our configuration files for each unknown object and pipeline step. \
They are saved in the [`configs_unknown` directory](./configs_unknown/).

## Project Summary
This project, which extends the code from our first solution, divides the problem into two phases. \
First, it performs a **convex reconstruction**, where an initial shape (an ellipsoid by default) is adapted to the lightcurves of the unknown object. \
Second, a **non-convex refinement** step is applied to retrieve features lost during the convex approximation. \
Each step is performed by an independent model trained on the challenge's public objects through a forward operator. This operator emulates the experimental setup of the lightcurves, balancing both real and Blender data.

For more details on the model architectures and training process, see [`train_convex.py`](./train_convex.py) and [`train.py`](./train.py).
